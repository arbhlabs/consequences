# FAQ

**Can I use the gate without points?** Yes. Use the core skill, runner and checklist on their own.

**Where do the scores come from?** The owner gives explicit positive or negative points. The agent may recognize praise or frustration and ask about recording it.

**Do I need a scheduler?** No. Views, weekly digests and charts generate when requested. The conversation hook runs when an agent with the add-on skill reads owner feedback.

**Does the runner find all secrets?** It checks common patterns in the supplied artifact. Use your repository's own secret scanning for broader coverage and history.

**Can I use the sample points without affecting real data?** Pass `--data-dir templates/points` only to read commands. Copy the sample files to a temporary folder before experimenting with awards.
