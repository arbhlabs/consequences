The principle

The owner is the customer.
Not the test lab.

The gate tests the artifact, not the agent's confidence. If a deliverable fails, it stays in the fix loop. If a defect reaches the owner, the agent records the lesson and updates both the artifact and the gate.

⌁

Cheap, scripted proof

Use deterministic scripts and a checklist instead of paying for another round of model opinions.

◈

Evidence-backed handoff

Require concrete artifact details, test results and visual review attestation where applicable.

↗

Lessons that persist

Every miss adds a checklist line, strengthening the gate against repeat failures.

Get started

Install in your workflow.

The installer fetches the latest skill and supporting templates from this repository.

macOS / Linux

curl -fsSL https://raw.githubusercontent.com/arbhlabs/consequences/main/install.sh | bash

Windows · PowerShell

irm https://raw.githubusercontent.com/arbhlabs/consequences/main/install.ps1 | iex

For other agents, copy the skill and templates into the agent's rules or skills directory. See the README for setup details and the gate runner interface.
