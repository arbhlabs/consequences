# Security policy

Report suspected vulnerabilities privately using the repository's Security tab and its private reporting option when available. If that option is unavailable, ask a maintainer for a private channel before sharing details.

Include the affected version or commit, the impact, and a minimal reproduction with synthetic data. Remove credentials and private paths from attachments. Give maintainers time to investigate before public disclosure.

The runner executes project-provided helpers with your permissions. Review those scripts before running them. The optional points bank stores plain local files. Keep its data directory, exports and charts private when they include real feedback.
