# Code of conduct

Treat contributors with respect. Keep feedback specific to the work and make room for different levels of experience.

Harassment, personal attacks, discrimination, and publishing another person's private information are grounds for moderation. Maintainers may remove content, restrict participation, or block accounts to protect the community.

Report public behavior to repository maintainers through GitHub. If discussing the incident publicly would expose private information, use GitHub's reporting features. Maintainers handle reports discreetly where possible.
